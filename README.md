# Mahjong Record (Mobile Mahjong Score Frontend)

모바일(6~6.5인치)을 타깃으로 한 **마작 라운드 기록용 웹앱 프론트엔드**입니다.  
한 번의 마작 파티 동안 각 라운드의 **등수만 빠르게 기록**하고, 날짜별 통계와 히스토리를 볼 수 있도록 만드는 것을 목표로 합니다.

백엔드는 Go + SQLite로 구현되어 있고, 이 레포는 **React + TypeScript + Tailwind CSS 기반 프론트엔드** 코드입니다.

화면은 Material 3의 앱 바, 색상, 표면, 타이포그래피 규칙을 따릅니다. 실제 MUI 런타임 패키지를 추가하지 않고 Tailwind와 semantic token으로 구현해 기존 번들 구조를 유지합니다.

## ✨ 주요 기능

### 🎴 마작 라운드 기록 (Record 탭)

- **모바일 우선 레이아웃**
  - 6~6.5인치 스마트폰에서 한 손으로 쓰기 편하도록 설계
  - 전체 컴포넌트가 가로 폭을 꽉 채우도록 구성
  - 상단 Material 앱 바 한 줄에 날짜 선택과 햄버거 메뉴를 배치
  - 햄버거를 누르면 우측 Drawer에서 네 개의 화면으로 이동
  - 다크 모드 전환은 Drawer 하단 설정에서 제공

- **플레이어 관리**
  - 플레이어는 칩(Chip) 형태로 표시되며 탭해서 **참가자(최대 4명)** 를 선택
  - 선택된 멤버가 있으면 목록을 기본적으로 접고, 헤더에서 다시 펼칠 수 있음
  - 플레이어 추가 시 **한글 이름 + 2자리 출생연도** 형식으로 제한
    - 예: `희재93`, `백호93`, `인섭02`
    - 정규식: `^[가-힣]{2}\d{2}$`
  - 성공/실패 시 스낵바(Snackbar)로 피드백 표시

- **이번 라운드 등수 정하기**
  - 오늘 같이 치는 플레이어 4명을 세션 멤버로 유지
  - 1위부터 4위까지 이름을 순서대로 탭해 기록
  - 저장 성공 후 세션 멤버는 유지하고 순위 초안만 초기화
  - **항상 4명을 모두 선택해야만 라운드 저장 가능**

- **오늘 날짜만 기록 허용**
  - 상단 날짜 선택이 가능하지만,  
    **오늘이 아닌 날짜가 선택되어 있으면 “라운드 저장” 버튼이 보이지 않음**
  - 백엔드에서도 안전하게 **오늘 날짜만 허용**하도록 한 번 더 검증

### 📊 통계 및 히스토리 (Stats 탭)

- **날짜별 통계**
  - 기록 탭에서 멤버를 선택했다면 해당 멤버만, 선택하지 않았다면 전체 참가자 표시
  - 예: 게임 수, 1위 횟수, 평균 순위 등
  - 라운드별 실제 1~4위 변화를 등수 흐름 그래프로 표시

- **라운드 히스토리**
  - 멤버 선택 시 해당 멤버가 참가한 라운드와 선택 멤버의 실제 등수만 표시
  - 멤버가 선택되지 않았다면 선택 날짜의 모든 라운드를 시간순으로 표시
  - 각 라운드마다:
    - 기록된 시각 (24시간 표기)
    - 1~4위 플레이어 이름 목록

- **전체 및 개인 통계**
  - 평균순위, 1위율, 연대율, 4위율과 등수별 횟수를 전체 표로 비교
  - 열 제목 정렬과 기간 필터 지원
  - 플레이어별 최근 10/20/50게임 등수 흐름 그래프와 순위 분포
  - 모바일 가로 스크롤과 태블릿 대응

### 🀄 오늘의 나니키루

- 선택 날짜에 대응하는 문제 제공
- 실제 손패 모양의 패를 직접 탭해 답 선택
- 최대 3회 시도와 오답 피드백
- 정답 또는 3회 실패 후 모범 답안, 해설, 유효패 정보 공개
- 날짜/문제가 바뀌면 이전 풀이 상태 자동 초기화

### 🌓 다크 모드 지원

- CSS semantic token과 Tailwind `dark` variant 사용
- 기존 `localStorage.colorMode` 값을 유지해 새로고침 후에도 선택 모드 복원

## 🧱 기술 스택

- **Framework**: React
- **언어**: TypeScript
- **스타일**: Tailwind CSS v4 + semantic CSS token
- **디자인 시스템**: Material 3 visual language + Noto Sans KR
- **상태 관리**: Jotai
- **차트**: Recharts
- **빌드**: Vite

일별 통계, 전체 통계, 나니키루는 탭에 진입할 때 지연 로딩됩니다. 따라서
차트 라이브러리와 문제 JSON은 기록 화면의 초기 번들에 포함되지 않습니다.
개인 통계 Dialog도 별도로 지연 로딩되므로 전체 데이터 표만 보는 경우에는
해당 Dialog 코드를 내려받지 않습니다.

날짜별 참가자는 `/api/rounds/by-date`의 `ranking`과 전체 플레이어 목록에서
파생합니다. 날짜 변경마다 `/api/players/by-date`를 중복 호출하지 않습니다.
